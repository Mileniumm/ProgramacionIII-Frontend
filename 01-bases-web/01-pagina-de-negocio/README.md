# Fresia - Comida Saludable 🥗

Proyecto de pag web para un lugar de comida saludable ambientado en el barrio de Güemes, Córdoba. Esta web fue desarrollada como parte de las prácticas de la materia programación III de mi tecnicatura.

## Características Técnicas Implementadas

- **HTML5 Semántico:** Estructuración limpia del documento utilizando etiquetas nativas como `header`, `nav`, `main`, `section`, `article`, `aside` y `footer`.
- **Reset de Estilos:** Normalización inicial de márgenes, rellenos y cálculo de caja (`box-sizing: border-box`) para asegurar consistencia entre navegadores.
- **Flexbox Layout:** Utilizado para la alineación del menú de navegación, distribución de secciones dentro del contenedor principal y orden estructurado en el pie de página.
- **CSS Grid Layout:** Aplicado estratégicamente en la sección "Armá tu propio Bowl" distribuyendo el menú interactivo en una grilla simétrica de dos columnas.
- **Responsive Design:** Implementación de Media Queries para asegurar la adaptabilidad de la interfaz en dispositivos móviles de hasta 768px de ancho.
- **Multimedia:** Inclusión de reproductores nativos de audio (`<audio>`) y video incrustado desde YouTube (`<iframe>`).

## Estructura del Proyecto

- `index.html` - Página principal del sitio.
- `about.html` - Sección institucional donde explico un poco de que trata la pag.
- `style.css` - estilos en general.
- `images/` - Carpeta que contiene imagenes
