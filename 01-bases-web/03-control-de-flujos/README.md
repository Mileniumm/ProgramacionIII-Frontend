# Control de flujos, ciclos e iteraciones

Ejercicios de JavaScript de la clase de control de flujos.

- **Ejercicio 1** (`Ejercicio-1.js`): pide nombre y edad. Con 18 años o más, la persona entra. Con 17, entra solo si su acompañante es mayor de edad. Con 16 o menos, no entra.
- **Ejercicio 2** (`Ejercicio-2.js`): calculadora con un menú de suma, resta y salir. El menú se repite con `do...while` y la opción se elige con `switch`. Avisa si los valores no son números y no deja restar si el primero es menor que el segundo.

## Cómo probarlos

Abrí `Ejercicio-1-HTML.html` o `Ejercicio-2-HTML.html` en el navegador y respondé las ventanas emergentes.
