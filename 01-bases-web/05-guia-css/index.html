Texto largo

Cuando un texto es largo, lo que más ayuda a leerlo en pantalla es darle aire entre líneas y no hacer los renglones demasiado anchos. Por eso este párrafo tiene un line-height de 1.6, está alineado a la izquierda y tiene un ancho máximo de unos 65 caracteres. Si lo justificara, el navegador estiraría los espacios entre palabras para llenar cada línea y quedarían huecos desparejos que cortan la lectura.
