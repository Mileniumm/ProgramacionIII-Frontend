# Flujos de datos

Los dos ejercicios de control de flujos, reescritos con más validaciones.

- **ej1:** el ingreso con control de edad. Revisa que el nombre no esté vacío y que la edad sea un número.
- **ej2:** la calculadora con menú. Si se cancela el `prompt`, sale con `break`; si la opción no es un número, vuelve al menú con `continue`.

## Cómo probarlos

Abrí `ej1.html` o `ej2.html` en el navegador y respondé las ventanas emergentes.
