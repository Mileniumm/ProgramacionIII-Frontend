# Formulario de encuesta

Encuesta para alumnos de Programación III, hecha con HTML y CSS.

## Qué tiene

- Campos de texto, email y número, con `required`, `min` y `max` para que el navegador valide solo.
- Un `select` para la condición del alumno y otro para la forma preferida de aprender.
- Botones de opción para saber si recomendaría estudiar programación y casillas para marcar las tecnologías que domina.
- Un `textarea` para comentarios y los botones Enviar y Limpiar.

## Cómo verlo

Abrí `index.html` en el navegador.
